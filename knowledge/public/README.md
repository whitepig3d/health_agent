# 公開資料の根拠カード

2026-11-04に公的サイトの該当本文を確認し、**16資料・47枚**を作成した。ステップ3の面談準備に必要な主要テーマを横断するレビュー用資料集である。国の全公開資料や全疾病・全判定条件を収録したものではない。

- [根拠カード一覧](根拠カード一覧.md)：有識者が読むためのMarkdown。
- [evidence_cards.json](evidence_cards.json)：機械処理用。既存カードの必須キーを保ち、出典・適用条件・レビュー情報を追加。
- [sources.json](sources.json)：採用資料のURL、版、確認日、取得状態。
- [収録範囲と確認記録](収録範囲と確認記録.md)：テーマ対応、選定理由、更新・未収録事項。

## 内容の読み方

`text`は作成者による資料の要約で、逐語引用ではない。`excerpt`は未収録のため`null`とした。`agent_usage`の質問例・利用方法は作成者の実装提案であり、公的機関が提示した質問文ではない。`applicability`・`exclusions`は資料の対象範囲に加え、誤適用を防ぐ設計上の条件を含む。これらの条件の医学的な十分性は有識者が確認する。

全カードは`reviewed: false`。出典を閲覧したことと、業務有識者が助言内容・適用条件を承認したことを区別している。`reviewer_id`と`reviewed_at`も未設定である。

PDFは`page.printed`が紙面記載のページ、`page.pdf_1based`がファイル先頭を1とするページ。HTMLの`page`は`null`で、見出しを`section`に記録した。

`retrieved_at`はWeb閲覧ツールで確認した日。原本ファイルはダウンロード・固定しておらず、`source_file_sha256`は`null`。閲覧時点の原本を再現できる状態ではない。`card_sha256`は当該キー自身を除いたカードの正規化JSONのSHA-256であり、原本の真正性や専門職の承認を証明しない。

## 現行デモとの関係

既存の`examples/demo/evidence_cards.json`は創作の模擬資料として維持した。本資料集に置換すると、現行`plan()`は未承認カードを除外し、根拠不足で停止する。これは想定どおりの動作である。

現在の`plan()`には以下の制限がある。

1. `reviewed`が真で、`common`または健診項目コードと`tags`が一致するカードのみ候補にする。
2. `conditions`が空でないカードは選ばない。本資料集は全件に条件があるため、承認フラグだけ変えても利用できない。
3. 選択結果は1〜8枚である必要があり、47枚をそのままプロンプトに渡す用途ではない。
4. `activity`、`sleep`、`alcohol`等の生活習慣タグを問診から付与する処理や、適用条件・除外条件の評価は未実装。

利用前には、原本取得・固定と有識者レビューを実施し、条件評価ができる選択処理へ接続する。条件を削除して現行処理を通すことはしない。対象者別の承認済み課題・問診・安全注意から選び、根拠不足の領域は助言を保留する。安全カードを優先し、通常の候補と合わせて8枚以内に整理した経緯を残す。固定のケース別回答選択にはしない。

## レビュー・更新手順

1. `sources.json`のURLから採用版の原本を保存し、訂正情報とファイルハッシュを記録する。HTMLも取得内容を固定する。
2. 各カードの指定箇所に戻り、要約、数値・単位、対象集団、本文・表・脚注を照合する。PDF本文抽出だけで確定できない表は目視確認する。
3. 有識者が適用・除外条件、他のカードとの競合、受診確認の優先度を確認する。必要な根拠抜粋も別フィールドに追加する。
4. 誰が何を確認したかを記録し、承認済みパックを別途版管理する。本資料集のチェックはレビュー前の状態を検査するため、承認後はその状態に合わせて検証契約も変更する。
5. 出典が更新された場合は該当`document_id`の全カードを再照合し、承認を引き継がない。自動的に新旧の数値を混ぜない。

## 検証

リポジトリ直下で実行する。

```bash
python tools/validate_public_cards.py
python -m unittest discover -s tests -q
```

検査対象はID・出典対応・ハッシュ・ページ・条件・レビュー状態・テーマ対応・Markdownとの一致。医学的正確性、最新制度への完全準拠、LLMの生成品質、リンクの将来の有効性はこの検査では保証しない。
