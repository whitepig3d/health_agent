# 公的資料に基づく根拠カード

厚生労働省の[特定健康診査・特定保健指導の円滑な実施に向けた手引き掲載ページ](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/handbook_31132.html)を起点に作成した、専門職レビュー前のカード集です。確認日は **2026年11月5日** です。

**38資料、詳細要点カード146枚、統合カード39枚、原文参照カード707枚（うちQ&A192問）、合計892枚**を収録しています。資料数・カード枚数の上限で打ち切らず、手引き全8章と付属PDF、統合Q&A、実施計画手引き、標準プログラム全編の分冊・別紙・関連マニュアル・参考様式まで対象を広げました。PDFの延べページ数は686です。ただし画像中の情報まで完全収録したという意味ではありません。

- [統合カード編集確認記録](統合カード編集確認記録.md)：主要な分岐・例外の原文照合と確認範囲
- [統合カード一覧](統合カード一覧.md)：19テーマを22枚に整理した判断・手順。必要情報、全分岐、例外・保留、結論・記録と複数出典

- [タグ整理・検索ガイド](タグ整理ガイド.md)：5軸・43タグの定義、個人業務との関連、件数・検索例

- [要点カード単独可読性の確認記録](要点カード単独可読性の確認記録.md)：全136枚の本文確認と修正内容
- [要点カード補完記録](要点カード補完記録.md)：支援区分・階層化等の不足22項目と追加ID
- [根拠カード一覧](根拠カード一覧.md)：要点136枚の全文と資料別の原文参照リンク

- [要点カードJSON](evidence_cards.json)：対象条件と出典抜粋を付けた要約

要点カードは、健診対象、検査条件、階層化、服薬、受診勧奨、本人の自己決定、支援計画、評価ポイント、ICT、契約・保存・実績報告、食事・運動・喫煙・飲酒・睡眠・口腔・非肥満者への支援を扱います。原文参照には要点に採らなかった制度事務や研修、質管理、様式等も残しています。

## カードの読み方

|項目|意味|
|---|---|
|`evidence_id`|要点は`K_...`、原文参照は`REF_...`。要点IDは編集入力で明示的に保持|
|`card_type`|`summary`は詳細要約、`integrated_summary`は複数原文を統合した判断手順、`qa`は問答一式、`source_excerpt`は抽出本文、`historical_reference`は旧制度の改訂履歴|
|`text`|要点では要約、原文参照では抽出テキスト。意味が異なるので種類を確認|
|`citations`、`sections`|統合カードの全出典（範囲・抜粋・版・ハッシュ）と本文の構成・出典キー。単一出典欄は第一出典|
|`related_detail_ids`|統合カードの関連詳細要点ID|
|`source_excerpt`|要点の根拠になった抽出本文。改行・外字・ページ末尾の文字等は未校正|
|`source_id`、`url`、`edition`|資料・版・原本PDFへのリンク|
|`source_location`|**PDFの先頭を1ページとするページ位置**と、保存スナップショットの抽出行位置。冊子の印刷ページとは異なる|
|`conditions`|資料の適用条件と、誤用を避けるための編集注記。逐語引用ではない|
|`related_evidence_ids`|前後の原文、または要点を裏付ける参照カード|
|`tags`|用途・個人業務との関連・業務段階・話題・運用の5軸。本人への適用可否や承認状態ではない|
|`classification`|分類理由、個人業務での参照範囲、編集草案状態、分類版|
|`reviewed`|すべて`false`。収集・抽出・構造検証を医学・制度の承認と区別|
|`source_excerpt_sha256`|抜粋の整合性を検証するハッシュ。原本PDFファイルのハッシュではない|

出典が同じでも、要点カードと原文参照カードは役割が異なります。枚数を独立した科学的根拠の数と解釈しないでください。制度手引き・運用Q&A・実務解説・様式は、すべて同じエビデンス水準の医学研究ではありません。

## ローカル検索

リポジトリのルートで実行します。外部APIへの送信はありません。

```bash
python tools/search_public_cards.py '服薬'
python tools/search_public_cards.py 'AI' --source QA20241025
python tools/search_public_cards.py --tag sleep
python tools/search_public_cards.py '再委託' --kind all
python tools/search_public_cards.py --id K_QA20241025_008 --json
python tools/search_public_cards.py --source HB43 --kind reference --json
```

既定は詳細要点・統合カードの両方です。`--kind integrated`は統合のみ、`--kind detail`は詳細要点のみです。統合カードへの`--source`は全出典を検索します。`--kind reference`で原文、`--kind all`で両方を検索します。スペース区切りの語はAND検索です。結果件数に上限は設けていません。`--individual-use relevant`で個人業務の参照候補を選択できます。`--tag`は複数指定するとAND条件、旧名の分割先はOR条件です。

## 現行エージェントとの関係

既存カードと共通のフィールドを備えていますが、**草案のまま`main.py plan`へ接続するためのデータではありません**。`reviewed=false`、`common=false`、明示的な適用条件を保持しています。現在の選択処理は未レビュー・条件付きカードを除外し、8枚超過でも停止するため、このコーパスをそのまま投入しても指導計画生成には使えません。

収録数の制限と、1回の生成に使うカードの選択制約は別問題です。今回、アプリの選択・承認処理や8枚制限は変更していません。専門職のレビューを行い、対象者に適用する条件と取得方法を別途設計してから接続してください。単に全カードを`reviewed=true`へ変更することはレビューになりません。

特にQ&Aの[AIによる自動支援の取扱い](https://www.mhlw.go.jp/content/12400000/001320648.pdf#page=7)は`K_QA20241025_008`に収録しています。AI生成・自動送信だけでは専門職による支援ポイントの算定対象になりません。

## 更新・再現

```bash
python tools/build_public_cards.py
python tools/validate_public_cards.py
```

- タグの編集入力は`tag_taxonomy.json`と`card_classifications.json`です。全カードの明示的な分類を保持し、本文等が変わると再確認を要求します。ビルド時にタグ整理ガイドも再生成します。
- 統合本文の編集入力は`integrated_specs.json`、出力は`integrated_cards.json`と`統合カード一覧.md`です。出典ごとの抽出範囲と関連詳細カードを保持し、分類台帳への登録・再確認が必要です。
- 要点本文の編集入力は`summary_specs.tsv`です。既存IDを保って要点・条件・根拠範囲を修正します。
- `source_text/*.json`はWeb取得結果のPDF抽出テキストを、行位置・ページ位置付きで重複除去した保存データです。原本PDFは同梱していません。
- ビルダーは保存データと編集入力からJSON・Markdown・網羅性レポートを再生成します。ネットワークへのアクセスは行いません。
- バリデーターは出典、版、ID、ページ、抜粋、ハッシュ、抽出行の網羅、Q&Aの問答対応、草案状態を検証します。医学的正確性・最新性や画像・図表の正しさは検証しません。
- 版を更新する際は、リンク先の差替え、本文・脚注・適用年度を確認し、新しいスナップショットと旧版との対応記録を残してください。今回の自動生成処理はレビュー状態を引き継ぎません。
