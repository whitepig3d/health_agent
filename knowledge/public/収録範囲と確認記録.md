# 収録範囲と確認記録

確認日：2026-11-04。対象は特定保健指導のステップ3で使う「確認質問・未合意の行動候補・支援候補」の根拠。現行設計の15〜25枚という事前検証用の目安を拡張した資料集であり、一度の生成で使うカード数を拡張するものではない。

## 主要テーマの対応

| テーマ | カードID（PUB_を省略） | 収録する内容と限界 |
| --- | --- | --- |
| 本人中心の支援・社会背景 | COMMON_01〜03 | 自己決定、家庭・職場・経済状況、継続支援 |
| 面談準備・目標・記録・フォロー | PLAN_01〜05 | 過去記録、意向、具体化、記録、連絡方法。制度の実績評価計算は含めない |
| 服薬・既往歴 | ASK_01 | 確認質問。治療指示はしない |
| 体重歴・活動・食習慣・咀嚼 | ASK_02〜03 | 問診で確認する事項。質問票の閾値を運動目標にしない |
| 飲酒・睡眠の問診 | ASK_04 | 飲酒日と全日平均を区別、休養感を確認 |
| 経年変化・複数リスク | RESULT_01 | 承認済み評価の説明支援 |
| 血圧・受診確認 | RESULT_02、BP_01〜03 | 受診確認、減塩、一般の予防目標、腎疾患への配慮 |
| 腎機能・尿蛋白 | RESULT_03、BP_03、GLUCOSE_04 | 受診・食事制限の確認。診断や全閾値の自動判定は含めない |
| 体重・腹囲・食事記録 | WEIGHT_01〜02 | 減量の必要性確認、食事の振り返り |
| 脂質 | LIPID_01〜03 | 脂質の種類、魚・乳製品、食物繊維。個別の治療食量は確定しない |
| 糖代謝 | GLUCOSE_01〜04 | 食事構成、飲料・間食、時刻、腎障害への配慮 |
| 食物繊維 | FIBER_01 | 食品選択の工夫。集団平均から個人の不足量を推定しない |

| 高齢者の運動 | OLDER_01〜02 | 身体機能、個別調整、転倒配慮 |
| 飲酒 | ALC_01〜03 | 純アルコール量、政策指標と許容量の区別、見直し方法 |
| 喫煙・受動喫煙 | SMOKE_01〜03 | 意向に応じた支援、相談先、環境への配慮 |
| 睡眠・交替勤務 | SLEEP_01〜04 | 時間と休養感、カフェイン、寝酒、勤務への配慮 |
| 非肥満者 | NONOBESE_01 | 支援の必要性と制度の対象資格を区別 |

上記はテーマの対応表であり、医学的な網羅率や全文を漏れなくカード化した割合を示すものではない。タグはローカル語彙で、JLAC10等の標準コード体系との対応は未実装。

## 出典の選定と更新の扱い

中心資料は[厚労省「標準的な健診・保健指導プログラム（令和6年度版）」掲載ページ](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000194155_00004.html)からリンクされた分割PDF。第3編第3章には2025-11-25更新、第2編別紙5・文例集には2024-03-21更新の表示を確認した。ページの更新表示と、各記述が変更された日を同一視しない。

身体活動、睡眠、飲酒は国のガイドおよび厚労省e-ヘルスネットの解説を使用した。栄養は同サイトの食事関連解説を採用し、本文に示された更新日を記録した。学会資料へのリンクがある場合でも、リンク先学会資料の全文を確認したとみなさず、実際に読んだ公的ページを出典とした。

資料の役割は分ける。標準プログラムは指導業務の基本、ガイドは一般的な推奨、疾患別解説は対象条件を伴う補助情報である。例えば一般の発症予防の食塩目標と疾病治療の制限、成人と高齢者の活動目安を一つの値に統合しない。治療中の人の個別指示は主治医等に確認する。

初版の出典16件は本文の該当箇所をWeb閲覧ツールで確認した。検索結果の短い紹介文だけからカードを作成していない。一方、原本ファイルの保存・ハッシュ化、全ページ・全脚注の監査、全リンク先の確認、有識者の医学的レビューは未実施。

## 未収録・採用を保留した範囲

| 範囲 | 理由・次の確認 |
| --- | --- |
| 階層化、動機付け・積極的支援の全要件、実績評価・請求 | 第4.3版から一部の制度条件を追補。全要件・評価点数・請求の計算は引き続き別管理とし、自動判定しない |
| 健診の全判定値、肝機能、尿酸、貧血、心電図、眼底等の個別対応 | 全条件・受診時期を未整理。数値から独自助言を作らず有識者に返す |
| AUDIT全設問・採点・点数別支援 | 公開PDFへの到達を確認したが本文抽出が乏しく、採点や分岐を未検証。今回採用しない |
| 食事摂取基準2025の全栄養素・年齢性別表 | 公的解説で確認できた範囲のみ収録。原報告書の全表を検証したものではない |
| 妊娠・授乳、摂食障害、重度低栄養、重症疾患の専門的支援 | 一般カードの単純適用を避け、専門職による別設計が必要 |
| 睡眠時無呼吸等の診断・治療、薬剤調整、緊急トリアージ | 計画案生成の範囲外 |
| 国民健康・栄養調査の数値カード | 集団の説明には有用だが、個人の原因・適正目標を決める根拠にはしない |

未収録テーマが入力にある場合は「根拠不足」として記録し、既存カードのタグを無理に当てはめない。
